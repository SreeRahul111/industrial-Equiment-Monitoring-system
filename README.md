# Industrial Equipment Monitoring System (IEMS)

Secure full-stack Industrial Equipment Monitoring System built from the IEMS Figma design.

## Stack
- Frontend: React + TypeScript + Vite
- Backend: FastAPI + SQLAlchemy
- Database: PostgreSQL target; SQLite supported for local testing
- Auth: JWT + RBAC
- Testing: pytest + frontend build/tests
- Infrastructure: Docker, Kubernetes, GitHub Actions
